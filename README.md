# Car Screen

เว็บแอปแบ่งจอสไตล์ Android Auto สำหรับมือถือ/แท็บเล็ต: แผนที่นำทางฝั่งหนึ่ง YouTube หรือแอปอื่นอีกฝั่ง

## ใช้งาน
เปิดผ่าน HTTPS (เช่น GitHub Pages) แล้ว “ติดตั้ง” เป็นแอปได้ (Android: ปุ่มติดตั้งในเมนู ⋯, iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม)

- **นำทาง** ค้นหาสถานที่หรือกดค้างบนแผนที่ → เริ่มนำทาง: บอกทางเลี้ยวเป็นภาษาไทยพร้อมเสียง, เวลาถึง, ความเร็ว, คำนวณเส้นทางใหม่เมื่อออกนอกเส้นทาง, ปุ่มส่งต่อไป Google Maps, เส้นทางทางเลือก (ป้ายบอกว่ามีค่าผ่านทางไหม), ตัวเลือกเลี่ยงทางเสียค่าผ่านทาง/ทางด่วน/เรือข้ามฟาก
- **YouTube** ค้นหาและเล่นในจอแบ่ง, วางลิงก์วิดีโอ/เพลย์ลิสต์, เล่นต่ออัตโนมัติ, ประวัติการดู, เข้าสู่ระบบ (ตัวเล่นใช้บัญชี youtube.com ในเบราว์เซอร์; ช่องที่ติดตาม/วิดีโอที่ชอบ/เพลย์ลิสต์ ผ่าน Google sign-in ซึ่งต้องใช้ OAuth Client ID)
- **แอปอื่น** เว็บทั่วไปเปิดในจอ; Netflix/Spotify ฯลฯ เปิดเป็นเว็บไซต์ใน Chrome ไม่เปิดแอป (เว็บเหล่านี้ไม่ยอมให้ฝังในจอแบ่ง)
- **หน้าจอ** ลากแถบกลางปรับขนาด, เมนู ⋯ ที่แถบกลาง: แผนที่เต็มจอ / แบ่งจอ / แอปเต็มจอ, สลับฝั่ง, แนวตั้ง/แนวนอน, เต็มจอ, ตั้งค่า ปุ่มต่างๆ ซ่อนเองเมื่อไม่ได้แตะ

## บริการที่ใช้
แผนที่ OpenStreetMap, ค้นหาสถานที่ Nominatim, เส้นทาง OSRM (เซิร์ฟเวอร์สาธิตฟรี), YouTube IFrame Player
การค้นหา YouTube ใช้เซิร์ฟเวอร์ Piped/Invidious สาธารณะ ซึ่งอาจล่มเป็นช่วงๆ ใส่ YouTube Data API key ในตั้งค่าเพื่อให้เสถียร
