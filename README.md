# Car Screen

แอปจอรถแบบแบ่งจอ หน้าตาแบบ Tesla: แผนที่นำทางฝั่งหนึ่ง แอป (YouTube, Netflix, เว็บอื่น ๆ) อีกฝั่ง
ใช้งานผ่านแอป Android (`android/`) ซึ่งเปิดหน้าเว็บนี้ทั้งจอ แล้ววางหน้าต่างเบราว์เซอร์จริงไว้บนฝั่งแอปและบนแท็บ Google Maps

ดาวน์โหลดแอป: https://rbblackhack0950.github.io/new-site-cm/dist/car-screen.apk

## ใช้งาน
- **ค้นหา** พิมพ์ชื่อสถานที่ → Google Maps เปิดเป็นแท็บบนฝั่งแผนที่ → แตะสถานที่ → **ไปที่นี่**
  (วางลิงก์ Google Maps หรือพิกัด หรือกดค้างบนแผนที่ก็ได้)
- **นำทาง** เส้นทางทางเลือกพร้อมป้ายค่าผ่านทาง, เลี่ยงทางด่วน/ค่าผ่านทาง/เรือ, บอกทางเลี้ยวภาษาไทยพร้อมเสียง, คำนวณเส้นทางใหม่เมื่อออกนอกเส้นทาง
- **แอป** แตะเพื่อเปิดในฝั่งขวา, กด **แก้ไข** เพื่อลบแอปไหนก็ได้ (มีเลิกทำ), **เพิ่มแอป** จากเว็บไซต์ใดก็ได้, คืนค่าแอปเริ่มต้นในตั้งค่า
- **แถบล่าง** ตั้งค่า · แผนที่ / แบ่งจอ / แอป · สลับฝั่ง · ทางลัดแอป · นาฬิกา
- **อัปเดต** หน้าจอและฟีเจอร์อัปเดตเองทุกครั้งที่เปิด ตัวแอป APK อัปเดตได้ที่ ตั้งค่า

## บริการที่ใช้
แผนที่ OpenStreetMap, เส้นทาง OSRM (เซิร์ฟเวอร์สาธิตฟรี), ค้นหาสถานที่ด้วย Google Maps เวอร์ชันเว็บ

## พัฒนา
```
npm test                 # Chromium จริง, จำลองบริการภายนอกและตัวแอป Android
SHOTS=out npm test       # บันทึกภาพหน้าจอ
android/build-apk.sh     # build APK โดยไม่ต้องมี Android SDK หรือ Gradle → dist/car-screen.apk
```
กุญแจเซ็นแอป (`android/carscreen.keystore`) เปิดเผยใน repo เพื่อให้ APK ใหม่ติดตั้งทับตัวเก่าได้ ใช้สำหรับติดตั้งเองเท่านั้น

## ข้อมูลที่ชาร์จ

- สถานีชาร์จเร็ว DC กว่า 3,000 แห่งมาจากแผนที่ "DC EV Charging Station Thailand" ของ ปิยเมษฐ์ วิษณุเวช (ฝังไว้ใน `data/dc-stations.json` ใช้ได้แม้ไม่มีเน็ต)
- แปลงข้อมูลใหม่ด้วย `tools/kml-to-json.py doc.kml data/dc-stations.json`
- รวมกับ OpenStreetMap (หัวชาร์จ AC และสถานีใหม่) โดยตัดสถานีซ้ำที่อยู่ห่างกันไม่เกิน 80 ม.

## ใช้งานเพิ่มเติม

- **บ้าน / ที่ทำงาน:** ปุ่มในช่องค้นหา แตะครั้งเดียวเพื่อนำทาง กดค้างเพื่อเปลี่ยน
- **สำรอง / ย้ายการตั้งค่า:** ตั้งค่า → สำรอง คัดลอกรหัส `CS1.…` ไปวางอีกเครื่อง
- **เส้นทางสำรอง:** ถ้าเซิร์ฟเวอร์ OSRM หลักล่ม จะใช้ routing.openstreetmap.de แทนอัตโนมัติ

## มุมมองขับรถ

ระหว่างนำทาง แผนที่หมุนให้ถนนข้างหน้าชี้ขึ้นเสมอ รถเป็นลูกศรอยู่ต่ำกว่ากลางจอ ปุ่มเข็มทิศมุมขวาบนสลับเป็น "เหนือขึ้นบน" ใช้ปลั๊กอิน [leaflet-rotate](https://github.com/Raruto/leaflet-rotate) (GPL-3.0, อยู่ใน `vendor/leaflet/`)

## ค้นหาตามเส้นทาง / ขั้นตอน / ซูมอัตโนมัติ

- ระหว่างนำทาง ปุ่มแว่นขยายในแถบล่างค้นหา ที่ชาร์จ ปั๊มน้ำมัน ร้านอาหาร ห้องน้ำ ที่จอดรถ ตามเส้นทางข้างหน้า (ข้อมูล OpenStreetMap)
- ปุ่มรายการ (หรือแตะป้ายเลี้ยว) แสดงขั้นตอนที่เหลือ และปุ่ม "ภาพรวมเส้นทาง"
- ซูมออกเมื่อขับเร็ว ซูมเข้าเมื่อใกล้ทางเลี้ยว (ปิดได้ในตั้งค่า) ถ้าซูมเอง ระบบเว้นให้ 20 วินาที
