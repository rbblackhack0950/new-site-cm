# Car Screen

เว็บแบบ Android Auto: แบ่งจอ Google Maps + แอปอื่น (YouTube ฯลฯ) ใช้บนมือถือ/แท็บเล็ต

เปิด `index.html` ผ่าน HTTPS (เช่น GitHub Pages) เพื่อให้ตำแหน่ง GPS ทำงาน

- ลากแถบกลางปรับขนาด, ⇄ สลับฝั่ง, ▥ แนวตั้ง/แนวนอน, ⛶ เต็มจอแต่ละฝั่ง, ⤢ เต็มจอทั้งเครื่อง
- YouTube: วางลิงก์วิดีโอ/เพลย์ลิสต์แล้วเล่นในหน้าได้
- Netflix/Spotify ฯลฯ บล็อกการฝัง iframe → เปิดเป็นหน้าต่างแยก
- ＋ เพิ่มแอปเอง (กดค้าง/คลิกขวาที่ปุ่มเพื่อลบ)
